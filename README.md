# Marble Studio Website

A polished bilingual marble and stone studio website built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- Responsive product browsing experience
- Bilingual interface
- Interactive 3D stone viewer
- Product search, quote flow, theme support, and motion effects

## Project walkthrough

The site presents a stone catalogue, lets visitors inspect product details, and guides them toward a quote request. The interactive viewer gives the product pages a tactile 3D layer while the responsive layout keeps the browsing flow usable on smaller screens.

## Tech stack

Next.js App Router, React 19, TypeScript, Tailwind CSS, Three.js, React Three Fiber, Drei, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Demo checklist

1. Browse the product catalogue and open a product detail view.
2. Test the bilingual navigation and theme controls.
3. Inspect the 3D stone viewer and submit the quote flow locally.
